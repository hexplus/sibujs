Chess as a reactive island

Every square below is server HTML. It is in the page before a line of JavaScript runs, and SibuJS never rebuilds it — it attaches bindings to the 64 buttons that are already there. The move list underneath is the opposite case: the server cannot know how many rows there will be, so that one region is mount()ed. One island owns both.

The rules come from chess.js. SibuJS owns the DOM, the reactivity and the lifecycle; it does not know what a knight is. Read chess-island.js — that file is the whole application.
